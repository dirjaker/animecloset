# Vestio 项目文档
# 原始需求文档已归档，此为开发用精简版

## 核心闭环
上传衣物 → 自动抠图+打标 → 衣橱管理 → 天气推荐 → 保存穿搭 → 日历展示

## MVP验收标准
1. 注册/登录
2. 上传衣物 → 自动抠图 → 展示透明背景结果
3. 衣橱查看（按类别筛选）
4. 天气推荐穿搭
5. 保存穿搭 → 日历展示卡通小人
6. 日历切换月份 + 点击查看详情
7. 捏人（发型/肤色）
8. 冷宫提醒（30天未穿）

## 外部服务
- 抠图: rembg (本地)
- 多模态LLM: DeepSeek Vision
- 文本LLM: DeepSeek Chat
- 天气: 和风天气
- 存储: 本地文件系统
