# 更新日志

格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.0.0/)。

## [1.0.0] - 2024-06

### ✨ 新增

#### 核心功能
- **衣橱管理**：衣物上传、分类、搜索、删除，支持 5 大标准分类（上衣/下装/外套/鞋/配饰）
- **多衣橱管理**：创建多个衣橱（如"日常"、"运动"、"正式"），支持衣物分配和拖拽
- **收藏功能**：一键收藏/取消收藏衣物
- **衣物生命周期**：记录购买日期和购买价格，计算每次穿着成本

#### AI 功能
- **AI 抠图**：使用 rembg（u2net 模型）一键去除衣物背景，生成透明 PNG
- **智能打标**：接入通义千问 VL（qwen-vl-plus），自动识别衣物颜色、材质、风格、季节、场合
- **穿搭推荐**：DeepSeek LLM 根据天气、场合、冷宫唤醒生成个性化穿搭方案
- **风格分析**：分析用户穿衣偏好，生成风格标签和搭配建议
- **AI 插画**：通义万相（wan2.7-image）将衣物平铺图转为 Q 版动漫风格穿搭插画
- **AI 衣物识别**：上传照片自动识别衣物类型

#### 穿搭系统
- **穿搭记录**：按日保存每日穿搭，自动记录天气和温度
- **穿搭日历**：日历视图展示每日穿搭记录
- **穿着统计**：自动追踪衣物穿着次数和最后穿着日期
- **冷宫唤醒**：推荐 30 天未穿的衣物，避免衣物被遗忘

#### 旅行打包
- **打包清单**：创建旅行打包清单，记录目的地和日期
- **AI 自动填充**：根据旅行天数自动从衣橱中推荐衣物

#### 天气系统
- **实时天气**：接入 wttr.in 免费 API，支持全球城市查询
- **天气预报**：3 天天气预报，包含逐时数据
- **和风天气**：可选接入和风天气 API 获取更精确的天气数据

#### 数据统计
- **衣橱概览**：各类别衣物数量、穿着总次数
- **穿着排行榜**：最常穿衣物 Top 10
- **冷宫衣物**：超过 N 天未穿的衣物列表
- **月度统计**：最近 12 个月每月穿搭次数
- **类别分布**：衣物分类占比
- **季节分布**：按季节标签统计衣物
- **穿着成本**：每次穿着成本分析（需录入购买价格）
- **穿着趋势**：最近 30 天每日穿着次数

#### 用户系统
- **注册/登录**：邮箱注册，JWT 令牌认证
- **个人信息**：昵称、性别、头像管理
- **头像上传**：支持图片上传作为头像
- **密码管理**：修改密码功能
- **每日提醒**：可配置每日穿搭提醒时间

#### 社交分享
- **分享图片生成**：将穿搭衣物拼接成拼图，叠加日期天气信息

#### 前端
- **毛玻璃暗色主题**：Naive UI 定制深色主题
- **响应式布局**：侧边栏导航 + 主内容区
- **路由守卫**：未登录自动跳转登录页
- **SPA 部署**：前端构建后由后端统一托管

### 🏗️ 技术架构

- **后端**：FastAPI 0.136 + SQLAlchemy 2.0（异步）+ SQLite
- **前端**：Vue 3.5 + Naive UI + Pinia + Vue Router + Vite 8
- **认证**：JWT（PyJWT）+ bcrypt（passlib）
- **AI 视觉**：通义千问 VL（qwen-vl-plus）
- **AI 文本**：DeepSeek Chat
- **AI 图像**：通义万相（wan2.7-image）
- **抠图**：rembg（u2net，本地推理）
- **HTTP 客户端**：httpx（异步）

### 🔒 安全

- CORS 限制为本地访问源
- JWT 密钥从环境变量读取，禁止硬编码
- 文件上传格式和大小校验
- SPA 中间件路径穿越防护
- SQL 注入防护（SQLAlchemy ORM 参数化查询）
- 用户数据完全隔离
