# 智能穿衣镜系统

> AI 智能穿衣镜：抠图、衣橱管理、天气穿搭推荐、AI插画

`Python` `FastAPI` `Vue.js` `PyTorch`

---

## ✨ 功能特性

- AI抠图
- 衣橱管理
- 天气穿搭推荐
- AI插画
- 风格分析

## 🚀 快速开始

```bash
# 克隆项目
git clone https://github.com/dirjaker/vestio.git
cd vestio

# 创建虚拟环境
conda create -n vestio python=3.12 -y
conda activate vestio

# 安装依赖
pip install -r requirements.txt

# 运行项目
python main.py
```
